# رادار بالعرب للتجارة الإلكترونية

مكتبة عربية أسبوعية لاختيار 4 إلى 5 أفكار لمحتوى Instagram يخدم أصحاب المتاجر وعملاء بالعرب. الأولوية للفائدة ثم الأنيميشن المتحقق منه ثم التفاعل الموثق. جميع التكييفات مقترحات للمراجعة.

دفعة التأسيس: 24 أكتوبر 2026. الجدولة المتفق عليها: الأحد 10 صباحًا بتوقيت عمّان. مصدر التقرير docs/index.html، ويحفظ سجل التعديلات في Git.

معاينات الفيديو من مزوديها وقد تنتهي روابطها، والمرجع الأصلي متاح لكل بطاقة. لا تتضمن الحزمة ملفات فيديو أو بيانات عملاء أو صادرات خام أو أسرار دخول.

كل صفحات HTML تحمل noindex مع فحص regression. noindex ليس تحكمًا بالوصول ولا ضمانًا مطلقًا، ولا يحكم صفحات GitHub نفسها.
